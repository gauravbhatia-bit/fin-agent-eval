A limit order includes a price boundary chosen by the person submitting it. In a simplified example, a buy limit sets the highest price the order may accept, while a sell limit sets a lowest price. The order can remain unfilled if the market does not meet that condition. Real order instructions and behavior depend on the venue, instrument, and provider, so this summary is incomplete. A limit price does not guarantee a fill or a complete fill. Other factors can affect whether an order is matched, and a displayed market price can change. This note is about terminology only; it does not recommend using a particular order type or selecting a price.

The separate market-versus-limit note discusses the broader trade-off. This document is deliberately similar so retrieval evaluation can test whether close topics are confused. It contains no live or fictional execution price.
